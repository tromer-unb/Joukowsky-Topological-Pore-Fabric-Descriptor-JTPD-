# Manuscript files

This directory contains the manuscript source associated with JTPD.

- `manuscript_jsg.tex` — Elsevier/Journal of Structural Geology manuscript source.
- `references.bib` — bibliography.
- `highlights.txt` — journal-style highlights.
- `JTPD_Overleaf.zip` — compact Overleaf-ready project.

In Overleaf choose **New Project → Upload Project**, upload the ZIP, and compile the manuscript. Before journal submission, verify authors, affiliations, funding, acknowledgements, permissions, and the final data/code availability statement.
